## Въпрос

Най-малкото възпроизводимо доказателство за catastrophic forgetting: секвенциално обучение на една и съща малка мрежа върху две задачи. Забравя ли мрежата Task A, докато учи Task B, без никаква защита - и ако да, доколко Elastic Weight Consolidation (EWC, Kirkpatrick et al. 2017, arXiv 1612.00796) наистина пази наученото, както твърди статията?

## Хипотези

H1: Обикновено секвенциално дообучение (без защита) причинява съществен спад в точността на Task A, след като мрежата се обучи на Task B.
H2: EWC регулация възстановява съществена част от загубената точност на Task A, спрямо обикновеното дообучение.

## Модел и данни

- **Задачи:** Permuted MNIST - Task A е оригиналният MNIST, Task B е същият датасет с фиксирана случайна пермутация на пикселите (стандартната настройка от самата EWC статия). Само публични данни (MNIST).
- **Модел:** MLP с два скрити слоя по 400 неврона, същия мащаб като в оригиналната статия - достатъчно малък да се обучи за минути на CPU, не изисква GPU.
- **Три обучения:** (1) Task A самостоятелно - базова точност; (2) Task A → Task B, обикновено секвенциално дообучение, без защита; (3) Task A → Task B, същото, но с EWC регулация върху параметрите, важни за Task A (Fisher information matrix, изчислена след Task A).

## Метрики

- Точност на Task A test set: след обучение на Task A, след Task B без EWC, след Task B с EWC
- Точност на Task B test set при двете условия (диагностика - проверява, че мрежата реално учи Task B, не просто се проваля навсякъде)

## Kill-gates (ПРЕДЛОЖЕНИ - чакат одобрение)

- **KG1:** Ако точността на Task A след обикновено дообучение на Task B не падне с поне **20 процентни пункта** спрямо точността веднага след Task A → H1 отхвърлена: обикновеното секвенциално дообучение не демонстрира убедително забравяне в тази постановка.
- **KG2:** Ако EWC не възстанови поне **50%** от загубената точност (спрямо разликата между KG1 базата и обикновеното дообучение) → H2 отхвърлена: EWC не защитава осезаемо в тази постановка, дори статията да твърди друго в своята.
- **KG3 (диагностичен, без праг):** точност на Task B при двете условия - проверка, че мрежата реално се обучава, не просто се проваля.

## Какво НЕ тества този експеримент

- Не тества Split MNIST или друга по-строга постановка с разделени изходни глави - Permuted MNIST е по-мека версия на проблема.
- Не тества EWC върху LLM или невронна мрежа с реален размер - целта е най-малкото възпроизводимо доказателство, не производствена постановка.
- Не сравнява EWC с други методи за continual learning (replay, LoRA-базирани подходи) - те са предмет на отделни записи в плана (#5, #19).
